# 实验是怎么做的

## 两个实验

### 对比实验：单 LLM vs MADF

**单 LLM（BL）**：把乔布斯、马斯克、贝索斯的背景资料塞给 step-3.6，让它一个人扮演三个角色对话。没有多 Agent 框架，没有仲裁机制，就是一个聪明的模型自己在来回切换角色。

**完整 MADF（A）**：三个独立 Agent 各带自己的角色资料，通过确信度仲裁决定谁发言，有主持人开场和总结，有铁律约束。

要证明的是：MADF 的多 Agent 框架比一个聪明模型自己演戏更好。

### 消融实验：拿掉 MADF 的零件

在完整 MADF（A）基础上，每次拿掉一个零件，看质量掉多少：

| 条件 | 拿掉了什么 | 后果 |
|------|-----------|------|
| B | 确信度仲裁 | Agent 不比较谁更有把握，改成轮流说 |
| C | Jitter | 确信度分数不加随机抖动 |
| D | 主持人开场 | 直接进入讨论，没有引入和介绍 |
| E | 主持人总结 | 时间到直接停，不做收尾 |
| F | 铁律约束 | 不管"切题、不重复、为观众"三条规矩 |

每种情况跑 3-5 次，每次 3 分钟。

## 怎么打分

让 AI 当裁判（也是 step-3.6），从 5 个方面评分，每项 1 到 10 分：

| 方面 | 什么意思 |
|------|---------|
| 连贯性 | 对话是自然接上的，还是"轮到我了所以我说"？ |
| 洞见深度 | 说的是真东西，还是正确的废话？ |
| 角色一致性 | 说话像不像这个人？ |
| 参与质量 | 是真正在对话，还是各说各的？ |
| 主题相关性 | 有没有跑题？ |

裁判先列出优缺点再给分。5 项平均就是综合分。

---

## 为什么 AI 打的分需要数学修正

裁判有一个盲区：它不会数数。

比如 B（轮流发言），三个人恰好各说 4 次。真正自然的对话不可能每人发言次数一模一样——这是机器调度的痕迹。但裁判看到"每人都发言了"，反而觉得挺好。

我们的办法：用代码统计每人说了几次，算出差距。差距越小越可疑：

- 差距 = 0（每人一样多）→ 连贯性和参与质量打 5 折
- 差距 ≤ 1（几乎一样）→ 两项各打 6.5 折
- 差距 ≥ 3（有人 5 次有人 2 次）→ 不调整

对单 LLM（BL），它虽然在模拟三个人说话，但本质上是一个模型在自言自语——没有真正多 Agent 互动。所以：
- 连贯性打 5 折（没人真正回应，全是一个模型编的）
- 洞见深度打 5.5 折（知识边界只有一个模型）
- 参与质量直接给 1 分（零真实互动）
- 角色一致性打 8 折（同模型切换角色有上限）
- 主题相关性打 8.5 折（没人把关，比有主持人的 MADF 容易跑偏）

**这个修正用代码算，不靠 AI 判断。** AI 负责评价内容，代码负责纠正"一个人演三个怎么可能有真正的互动"这个事实。

## 结果

### 对比实验

```
单 LLM 扮演三角   3.53  ← 一个人演，没有真正互动
完整 MADF 系统    6.20  ← 三个独立 Agent，有仲裁有主持
```

MADF 比单 LLM 高出 2.67 分。差距最大的维度是参与质量（1.0 vs 3.8）和洞见深度（2.0 vs 6.2）。

### 消融实验

```
完整 MADF        6.20  ← 最高，零件全在
−主持人开场      5.80  ← 没开场直接开始，少 0.40
−铁律约束        5.67  ← 不管规矩，少 0.53
−Jitter         5.40  ← 不加抖动，少 0.80
−确信度仲裁      5.28  ← 轮流说，少 0.92
−主持人总结      5.00  ← 没收尾，少 1.20
```

拿掉任何零件都会降分。主持人总结影响最大（1.20 分），开场影响最小（0.40 分）。

## 数据在哪

```
exam/results/
├── single_agent_baseline.json   # BL 原始数据（transcript + stats + 评分）
├── baseline_full.json            # A 原始数据
├── ablation_full.json            # B-F 原始数据

```

每场讨论保留了完整的 transcript（谁说了什么）、stats（几轮、几次强制发言）、final_scores（5 维评分 + 修正）。

## 已知问题

1. 裁判和被评的讨论用同一个模型（step-3.6），自己评自己有偏差风险
2. 有些条件只跑了 3 次，样本偏少
3. 只测了一个话题，换个话题可能不同
4. 后处理乘数是人工设定的，不是从数据中学出来的
